# Security Policy

## Supported versions

Security fixes are considered for the latest published release of E7 Shop
Reroller. Older releases may not receive separate updates.

| Version | Security support |
| --- | --- |
| Latest v1.x release | Supported |
| Older releases | Update to the latest release |

## Report a vulnerability privately

**Do not post exploitable details, credentials, logs containing personal
information, or proof-of-concept exploits in a public GitHub issue.**

1. Open the repository's [Security Advisories](https://github.com/TemperedTyrant/e7-shop-reroller/security/advisories).
2. Select **Report a vulnerability** to submit a private report.
3. Include the affected version, environment, impact, reproduction steps,
   and a suggested fix if available. Share sensitive evidence only through
   the private report.

If **Report a vulnerability** is unavailable, open a public issue **without
vulnerability details** asking the maintainer to provide a private reporting
channel. The maintainer will arrange a suitable contact method.

The maintainer will review reports as availability permits. There is no
guaranteed response or remediation deadline. Confirmed vulnerabilities may
be fixed in a new release and disclosed through a GitHub Security Advisory.

## Scope

Reports should concern vulnerabilities in this repository or its distributed
packages, such as unsafe file handling, privilege escalation, dependency or
release integrity issues, or unintended behavior that could compromise a
user's system.

Game bugs, account restrictions, and the publisher's rules for automation
are outside this project's security-reporting scope. The application is
unofficial and is not affiliated with the game's publisher.
